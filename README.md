# easy-generator-auth-fe

This is the front-end application for the Auth App, built using React.js.

## Installation

To set up the project locally, follow these steps:

1. Clone the repository:
    ```sh
    git clone git@github.com:sarah-mosbah/easy-generator-auth-fe.git
    ```

2. Navigate to the project directory:
    ```sh
    cd easy-generator-auth-fe
    ```

3. Install the dependencies:
    ```sh
    npm install
    ```

## Usage

To start the development server, run:
```sh
npm start
```

## Pages

The application includes the following pages:
- **Sign Up Page:** Allows users to create a new account.
- **Sign In Page:** Allows users to log in to their account.
- **Confirmation Page:** Displays a confirmation message after successful sign-up.
- **Home Page:** A basic home page accessible after logging in.
